# 周边去哪

说一句想怎么玩，它挑出附近真值得去的地方，并按最优顺序把路线排好。

[English](README.en.md)

---

## 它能做什么

**用一句话说需求。** 不用勾参数，直接写「想找能坐下来喝咖啡、人不多的老街区」。

**出发点有两种给法。** 用浏览器定位，或者在地图上点一下。地图选点开成全屏浮层，选完即关。

**偏好可以不填。** 想说细一点就展开「偏好」：同行人数、拥挤容忍度、想去哪。
留空的它会按默认值处理，并明确告诉你它假设了什么，而不是假装你说过。

**推荐一条条出现，不用等全部生成完。** 等待时能看到它进行到哪一步；随时可以按「停止」，
停下之后还能「补完剩下的」。

**推荐是分档的，每条都说清理由。**

- 分「首选」「备选」，并标出它最突出的那一点（「最出片」「雨天 / 高温可用」）
- 每条都说清适合什么、代价是什么
- 点「详情」可以看到：为什么推荐、最佳时段、费用、拥挤度、交通，以及
  **如果只去这一个**该怎么玩
- 它还会交代这次的假设、哪些没核实，以及排除了哪些地方、为什么排除

**挑不出来可以追问。** 对一个地点追问，或者对整批不满意，直接说「换几个不那么挤的」。

**一处能看多种内容的地方可以拆开。** 像「集美学村」这种，勾选后会拆成龙舟池 /
集美大社 / 嘉庚建筑群这样的独立站点——只有拆开才能逐段规划路线。

**选够了就规划路线。** 按最优拜访顺序排，出行方式**逐段**定：两个地方近就走路，
远的那一段才坐车。还可以设一个终点（比如回家）；不设的话，最后一站就是结束。

**两种看法，一份状态。** 「列表」看每个地方的介绍，「行程」看一条按顺序的时间轴：
第 N 站、每一段怎么走、多久、多远。来回切换不会丢编号和顺序。

**地图上能直接看。** 编号标记加路线折线，每个地点都有跳转高德的入口。

**天气会影响推荐。** 说有降水，就少推户外、多推室内。首页的天色跟着当前天气和时段走。

## 它不会骗你的地方

这是这个项目最在意的一件事：

- 距离标的是**直线距离**，界面上就写「直线」——真实里程要等路线规划出来才有
- 时间轴**不排时刻表**。不知道你会待多久、不知道店几点开门，就不编一个时间出来
- 高德核实不到的地点**会留着并标注**「高德未能核实」，而不是悄悄丢掉
- **拿不到天气就不提天气**，并且明说「天气未知，室内外未据此调整」，不让推荐层自己猜
- 某一段路没规划出来，就说「有 N 段没规划出来」，不拿「0 分钟 0.0 公里」冒充结果

## 快速启动

需要 Node 20.9 或以上。

```bash
npm install
cp .env.example .env.local
npm run dev
```

然后打开 http://localhost:3000 。

**想完全不填 Key 先跑一遍**，在 `.env.local` 里加这三行：走演示数据（真实厦门地名），
核实与路线也都用本地假数据，不必消耗任何额度。

```bash
RECOMMEND_PROVIDER=mock
RECOMMEND_VERIFY=mock
ROUTE_PROVIDER=mock
```

**想接真实数据**，把这些填进 `.env.local`：

| 变量 | 干什么用的 |
| --- | --- |
| `AMAP_WEB_SERVICE_KEY` | 服务端查坐标、直线距离、营业状态、规划路线、取天气 |
| `NEXT_PUBLIC_AMAP_JS_KEY` | 在浏览器里渲染地图，类型要选「Web端(JS API)」 |
| `AMAP_JS_SECURITY_CODE` | 配合上面那个地图 Key |
| `DEEPSEEK_API_KEY` | 服务端调用推荐模型 |
| `DEEPSEEK_MODEL` | 模型 ID。先跑 `npm run models` 看你的账号能用哪些，别照抄 |

填完之后把 `RECOMMEND_PROVIDER` 改成 `skill`，才会走真实推荐。

**关于 Key：** 只需要填进 `.env.local`，它不会被提交。仓库里的 `.env.example` 里
**没有任何密钥**——那是给人复制用的模板，密钥栏一律是空的，只有几个非敏感的默认值
（并发上限、各 provider 的取值、接口地址）。其中 `NEXT_PUBLIC_AMAP_JS_KEY` 会进浏览器，
所以要按高德的要求配好域名白名单。

没有高德 Key 时，地图那一块会提示加载失败，列表和行程照常能用。

## 页面

| 路径 | 是什么 |
| --- | --- |
| `/` | 首页：说需求、选出发点 |
| `/plan` | 推荐结果：列表与行程、地图、挑选、规划路线 |
| `/sky` | 天气层预览：把多种天气 × 昼夜摆在同一屏，调天气界面时用 |
